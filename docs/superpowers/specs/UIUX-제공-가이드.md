# UI/UX 디자인 제공 가이드

이 문서는 UI/UX 디자인을 제공할 때 필요한 형식, 파일명, 구조를 정의합니다.

---

## 📺 화면 목록

게임에는 다음 화면들이 있습니다.

### 1. 진행자 화면 (Host Screen)
**역할:** 방 생성, 플레이어 관리, 게임 진행 제어

**상태/페이즈:**
- `host-lobby`: 로비 (플레이어 입장 대기)
- `host-night`: 밤 페이즈 (플레이어 행동 중)
- `host-day_reveal`: 낮 - 결과 공개 (데미지 표시)
- `host-day_discussion`: 낮 - 토론 (플레이어 토론 중)
- `host-day_vote`: 낮 - 투표 (투표 진행 중)
- `host-game_over`: 게임 종료 (승자 표시)

### 2. 플레이어 화면 (Player Screen)
**역할:** 게임 참여, 밤 행동 선택, 낮 토론/투표

**상태/페이즈:**
- `player-lobby`: 로비 (방 입장, 닉네임 입력)
- `player-night`: 밤 페이즈 (행동 선택)
- `player-day`: 낮 페이즈 (토론/투표, 결과 공개 포함)
- `player-game_over`: 게임 종료 (결과 표시)

### 3. TV 화면 (TV Screen) - *선택사항*
**역할:** 공용 표시 화면 (선택 사항 - 필요시만 디자인)

**상태:**
- `tv-game`: 게임 진행 상황 표시

## 📝 마크다운 파일 템플릿

각 화면별로 마크다운 파일을 다음 형식으로 작성해주세요.

```markdown
# [화면명] - [상태명]

## 📐 화면 개요
[이 화면의 목적과 역할을 한 문장으로 설명]
예: "플레이어가 밤 페이즈에서 행동을 선택하는 화면"

## 🎨 시각적 특징
- 배경색/이미지: [설명]
- 레이아웃: [상/중/하, 좌/우 등]
- 전체 분위기: [톤앤매너]

## 📋 요소 목록

### [섹션명] (예: 헤더)

#### 1. 요소명
- **내용/텍스트**: [화면에 표시되는 텍스트]
- **상태**: [기본/활성/비활성/호버]
- **색상**: [색상명 및 hex 코드, 예: 금색 #c7a55a]
- **크기**: [상대크기 또는 px, 예: 크게, 24px]
- **폰트**: [폰트명, 굵기, 예: Noto Serif KR, 700]
- **위치**: [화면 내 위치, 예: 상단 중앙]

#### 2. 버튼명
- **텍스트**: [버튼에 표시되는 텍스트]
- **기본 상태**: [색상, 스타일]
- **호버 상태**: [마우스 올렸을 때의 변화]
- **활성 상태**: [조건과 스타일]
- **비활성 상태**: [조건과 스타일]
- **클릭 동작**: [클릭했을 때 일어나는 일]

#### 3. 데이터 표시 (예: 플레이어 목록)
- **형식**: [카드형, 리스트형 등]
- **표시 정보**: [각 항목에 표시되는 정보]
  - 플레이어 이름
  - HP / 상태
  - 아이콘 / 역할 표시
- **개수**: [표시되는 최대/최소 개수]
- **정렬 순서**: [어떻게 정렬되는지]

## 🔄 상태 변화 및 상호작용

### 데이터 업데이트
- [언제 화면이 업데이트되는가]
- [어떤 정보가 실시간으로 변하는가]

### 사용자 상호작용
- [어떤 버튼/요소와 상호작용 가능한가]
- [클릭/터치 시 어떤 일이 일어나는가]

### 특수 동작
- [애니메이션이 있는가]
- [타이머/카운트다운이 있는가]
- [알림/경고 메시지가 있는가]

## 📱 반응형 고려사항
- 모바일 (375px): [어떻게 표시되는가]
- 태블릿 (768px): [어떻게 표시되는가]
- TV (1920px+): [어떻게 표시되는가]

## 🎯 특수 고려사항
- [색상 맹 사용자 대응]
- [큰 텍스트 설정 지원]
- [기타 접근성 요구사항]
```

### 마크다운 작성 예시
```markdown
# 진행자 화면 - 로비 상태

## 📐 화면 개요
플레이어가 입장할 때까지 방 코드를 표시하고, 플레이어 목록을 관리하며, 게임 시작을 제어하는 화면입니다.

## 🎨 시각적 특징
- 배경색: 어두운 갈색 (#12131a)
- 레이아웃: 상단 헤더 → 중앙 플레이어 목록 → 하단 버튼
- 분위기: 느와르 (1930년대 사건 기록실)

## 📋 요소 목록

### 헤더 섹션

#### 1. 타이틀
- **내용/텍스트**: "집중표적게임"
- **색상**: 밝은 갈색 #f0e7d4
- **크기**: 아주 크게 (2.4rem)
- **폰트**: Noto Serif KR, 700
- **위치**: 상단 중앙

#### 2. 방 코드 표시
- **내용/텍스트**: "ABC1" (동적 생성)
- **색상**: 금색 #c7a55a
- **크기**: 매우 크게 (3rem)
- **폰트**: Special Elite (타이프라이터)
- **배경**: 반투명 검은색

### 중앙 섹션

#### 3. 플레이어 목록
- **형식**: 카드형 그리드 (2~3열)
- **표시 정보**:
  - 플레이어 이름
  - 준비 상태 (대기/준비됨)
- **개수**: 6~10명
- **정렬**: 입장 순서

### 하단 섹션

#### 4. 게임 시작 버튼
- **텍스트**: "게임 시작 (N/6~10명)"
- **기본 상태**: 6명 미만 시 회색 (비활성)
- **활성 상태**: 6명 이상 시 금색 배경
- **호버**: 더 밝은 금색
- **클릭 동작**: 게임 시작

## 🔄 상태 변화 및 상호작용

### 데이터 업데이트
- 플레이어 입장/퇴장 시 목록 실시간 업데이트
- 플레이어 수 변화에 따라 "게임 시작" 버튼 활성/비활성 전환

### 사용자 상호작용
- "게임 시작" 버튼: 클릭하면 게임 시작 (밤 페이즈로 전환)

## 📱 반응형 고려사항
- 모바일 (375px): 플레이어 카드 1열, 폰트 작게
- 태블릿 (768px): 플레이어 카드 2~3열
- TV (1920px+): 플레이어 카드 4열, 폰트 크게

## 🎯 특수 고려사항
- 진행자만 접근 가능한 화면
- 반응형 레이아웃 필수
```

## 🖼️ 이미지 파일 요구사항

### 형식
- **권장**: PNG (투명도 지원) 또는 SVG (확장성)
- **대체**: JPG (품질이 높은 경우)

### 크기
- **기본**: 1280 × 720px (16:9 비율)
- **최소**: 960 × 540px
- **최대**: 1920 × 1080px

### 내용
- 실제 화면에 표시될 **모든 요소** 포함
- 텍스트는 **더미 텍스트가 아닌 실제 내용** 사용
- 색상, 폰트, 버튼 스타일 모두 포함
- 다양한 상태 필요시 별도 이미지로 표시 (예: 버튼 활성/비활성)

### 주의사항
- 이미지만으로는 부족함 (마크다운과 함께 제공 필수)
- 고대비/선명한 이미지 권장 (색맹 사용자도 구분 가능하게)

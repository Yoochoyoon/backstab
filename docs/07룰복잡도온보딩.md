## 개요

신규 플레이어 기준 규칙 설명 목표 시간을 5분 이내로 잡고, 이를 달성하기 위한 설명 방식(진행자 구두 + 앱 내 역할 설명)과 초보자 적응을 돕는 첫판 힌트 기능을 정했다.

## 결정 사항

* **설명 목표 시간:** **5분 이내.** 캐주얼 파티용 게임이므로 진입장벽을 낮추는 것을 우선한다.
* **설명 방식 분담:**
  * **진행자(구두):** 핵심 흐름만 — "역할이 있고, 밤에 능력을 쓰고, 낮에 토론·투표한다" 수준의 큰 그림.
  * **앱('내 역할 설명' 화면):** 육탄방어 선택지, 합공 데미지 합산, 긴급처형 적용 대상 등 세부 규칙은 개인 앱 화면에 상주시켜, 게임 진행 중에도 언제든 다시 확인 가능하게 한다.
* **첫판 힌트:** 앱에 **1~2라운드까지만** 짧은 툴팁을 띄운다(예: 밤 페이즈에 "지금은 밤입니다, 공격할 사람을 고르세요"). 3라운드부터는 자동으로 사라져 기존 플레이어에게는 거슬리지 않는다. `03라운드진행.md`에서 1라운드가 전투 없는 "탐색 라운드"로 정해져 있어, 자연스러운 적응 구간과 맞물린다.

## 상세 규칙/수치

**진행자용 5분 설명 초안** (기존 결정 사항들을 이 순서로 압축):

1. (30초) 컨셉 한 줄: 보스의 충직한 조직원 중에 스파이와 배신자가 섞여있다.
2. (1분) 역할 4종과 승리조건 한 줄씩: 보스(스파이·배신자 전원 제거), 조직원(보스 생존), 스파이(보스 암살), 배신자(최후의 1인).
3. (1분30초) 라운드 흐름: 밤(능력/기본공격 동시 지목) → 낮(결과 공개 → 토론 → 투표로 데미지).
4. (1분) 세부 능력은 각자 앱의 '내 역할' 화면에서 확인하라고 안내.
5. (1분) 1라운드는 전투 없이 스파이끼리 정체만 확인하는 탐색 라운드임을 안내, 진행자 관리 화면과 시작 버튼 소개.

## 밸런스 고려사항 / 트레이드오프

* 세부 규칙을 앱으로 위임하면 구두 설명은 짧아지지만, 앱 UI 자체가 직관적이지 않으면 오히려 혼란이 커질 수 있다 — 앱 UI/UX 설계 시 "내 역할" 화면 가독성이 중요해짐.
* 첫판 힌트를 1~2라운드로 한정한 것은 반복 플레이어의 피로도를 낮추기 위함이지만, 진짜 초보자만 있는 그룹에서는 2라운드 이후에도 헷갈릴 수 있다 — 플레이테스트로 힌트 기간이 충분한지 확인 필요.

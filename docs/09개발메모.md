- **스택**: Node.js + TypeScript + Express + Socket.IO 백엔드, 빌드 도구 없는 순수 HTML/CSS/JS 프론트(React 사용 안 함), Render.com 배포 예정.
- **상태 저장**: 메모리에만 저장 — DB 없음. 서버가 재시작되면 진행 중이던 모든 방이 초기화된다(MVP 한정 허용).
- **MVP 구현** (2026-08-06): 8명 고정 입장, 역할 자동배정, 닉네임 중복 방지, 1라운드 탐색 라운드(스파이 서로 정체 확인, 전투 없음), 2라운드부터 기본 공격 + 역할별 특수 능력(보스 긴급처형·조직원 육탄방어/충성심서약·스파이 교란작전·배신자 흑막의미소) 처리, 낮(결과공개 → 토론 → 투표), 동점 시 재투표, 승리조건 판정, 진행자의 타이머 강제진행·연장, 첫판(1~2라운드) 힌트 툴팁, 진행자/TV 화면 통합.

## 코드 짜면서 새로 정한 것들 (기획 문서엔 없던 세부사항)

- **진행자(host)는 8명 역할에 포함되지 않는 별도 컨트롤러**로 구현했다. `06컴포넌트테크구현.md`에는 "진행자도 역할을 겸해 참가할 수 있다"고 돼 있지만, MVP에서는 진행자=관전+컨트롤 전용이고 겸직은 2차 작업으로 미뤘다.
- **TV 화면은 자동 연결이 아니라 방 코드를 직접 입력**해서 연결한다(추후 QR코드 등으로 개선 가능).
- **자기 자신은 밤 지목/낮 투표 대상에서 제외**된다(자기공격·자기투표 불가) — 문서에 명시되지 않아 상식적으로 정한 부분.
- **결과 공개(낮 데미지 공개) 페이즈는 타이머가 없다** — 진행자가 화면에서 "토론 시작하기" 버튼을 눌러야 다음(토론)으로 넘어간다.
- **방 코드는 헷갈리는 문자(0/O, 1/I)를 제외한 4자리**로 자동 생성된다.

## 능력별 세부 구현 결정 (04핵심메커니즘.md 기준으로 코드로 옮기며 확정한 것)

- **육탄 방어 절반 경감은 내림(floor)** 처리. 예: 데미지 3 → 절반 경감 시 1.
- **육탄 방어 쿨타임 "1라운드"** = 사용한 라운드(N)의 바로 다음 라운드(N+1)엔 사용 불가, N+2부터 재사용 가능.
- **교란 작전은 그 자리(같은 라운드)에서 대상의 밤 행동 전체를 무효화**한다 — 모든 행동이 동시 제출되므로, 서버가 방어/공격 단계보다 먼저 침묵 대상을 판정해 걸러내는 방식으로 구현.
- **흑막의 미소의 HP 회복은 "이번 라운드 밤 전투로 발생한 사망자 수 × 2"** 만 반영한다(낮 투표 사망은 별개 페이즈라 카운트하지 않음).
- **배신자 "이중 스파이" 패시브는 보류**: 원래 "조사 카드/능력을 받으면 50% 확률로 위장"이라는 규칙인데, 이 MVP엔 대응하는 "조사" 계열 능력 자체가 없어 트리거할 지점이 없다. 나중에 조사형 능력이 추가되면 같이 구현.
- **스파이 "암둠의 공모"**: 별도 신호 UI 대신 `spy:teammate_preview` + 동료 스파이 현황 패널로 같은 목적을 달성했고, 2026-08-21에 별도 구현은 하지 않기로 확정했다.

## 검증한 것

- `resolveRound.ts`(밤 데미지 합산·능력 처리·낮 투표·승리조건 판정) 유닛 테스트 16개 통과.
- 타입체크(`npx tsc --noEmit`) 통과.
- `socket.io-client`로 8명+진행자를 실제 로컬 서버(`npm run dev`)에 접속시켜 방생성→입장→1라운드 정찰(스파이 상호 확인 확인)→2라운드 밤에 조직원 육탄방어(흡수)로 보스 피해를 대신 받는 것까지 소켓 통신으로 end-to-end 검증(스크립트는 검증 후 삭제, 커밋 안 됨).
- 브라우저 여러 탭으로 8명 풀 플레이: 1라운드 정찰 → 2라운드(보스 긴급처형 2배 데미지, 조직원 충성심서약으로 공격 무효화) → 3라운드(힌트 소멸, 소진 능력 제거) 시나리오 직접 확인. Render.com 라이브 배포(https://jipjung-game.onrender.com)에서도 전체 흐름 정상 작동 검증.
- 진행자/TV 화면 통합: 하나의 페이지에서 위쪽은 공용 TV 영역(플레이어 상태, 결과 표시), 아래쪽은 진행자 컨트롤(강제진행, 시간연장)을 함께 표시.

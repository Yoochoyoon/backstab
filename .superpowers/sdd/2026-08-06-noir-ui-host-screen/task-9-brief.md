# Task 9: 통합 검증 및 문서 업데이트

## Summary

이 마지막 Task는 Task 1~8의 모든 변경사항이 함께 동작하는지 브라우저에서 종합적으로 검증하고, 개발 로그를 업데이트한다. 느와르 UI 구현이 완전히 작동하고, 기존 게임 기능을 보존하며, 접근성과 반응형 설계를 만족하는지 확인한다.

## Acceptance Criteria

- ✅ 로비 화면: 방 코드 명확, 플레이어 목록 업데이트, 시작 버튼 표시
- ✅ 게임 진행: 헤더(CONFIDENTIAL CASE FILE, 라운드, 페이즈, 타이머) 명확
- ✅ 느와르 스타일: 보스 카드 크게, 플레이어 카드 그리드, 모두 갈색/금색 테마
- ✅ HP 정확도: 보스 80%, 비보스 75% 검증
- ✅ 페이즈 전환: 밤(어두움) ↔ 낮(밝음) 배경 전환 부드러움
- ✅ 타이머 상태: 30초 이하 주황색, 10초 이하 크림슨색 + 깜빡임
- ✅ 반응형: 375px(1열), 768px(3열), 1920px(4열) 검증
- ✅ 접근성: 텍스트 대비 4.5:1, 버튼 44×44px, prefers-reduced-motion 존중
- ✅ 기능: 방 생성/입장/진행/강제진행/시간연장 모두 작동
- ✅ 성능: Lighthouse 60점 이상, 애니메이션 부드러움

## Testing Checklist

### 1. 로비 화면 (10분)
```
npm run dev → http://localhost:3000/host
- [ ] 헤더 "집중표적게임" 보임
- [ ] "방 만들기" 버튼 클릭 → 방 코드 생성 (예: "ABC1")
- [ ] 방 코드 명확하게 표시됨
```

### 2. 플레이어 입장 (5분)
```
http://localhost:3000/player (5개 탭)
- [ ] 플레이어 5명 이상 입장
- [ ] 호스트 화면에서 플레이어 목록 실시간 업데이트
- [ ] 입장한 플레이어 수 "시작 (N/6~10명)" 표시
```

### 3. 게임 시작 및 스타일 (15분)
```
호스트 화면 "시작" 버튼 클릭 → 게임 시작
- [ ] 헤더 명확함
  - [ ] "CONFIDENTIAL CASE FILE" 라벨 보임 (타이프라이터 폰트)
  - [ ] "집중표적게임" 제목 보임 (세리프 폰트)
  - [ ] 라운드 "Round 1" 보임
  - [ ] 페이즈 "정찰" 보임
  - [ ] 타이머 크게 표시 (금색)
- [ ] 보스 카드 명확함
  - [ ] 보스 카드 왼쪽 또는 상단에 크게 표시
  - [ ] 금색 테두리 보임
  - [ ] "BOSS" 라벨 보임
  - [ ] 보스 이름 + HP 표시 (예: "HP 5/5")
- [ ] 플레이어 카드 그리드
  - [ ] 카드들이 그리드로 정렬
  - [ ] 각 카드에 플레이어 이름 + HP 표시
  - [ ] 종이색 배경, 테두리 있음
```

### 4. HP 정확도 (10분)
```
밤 페이즈에서 데미지 발생
- [ ] 보스 HP 5 → 4: HP바 80% 표시 (보스는 MAX_HP=5)
- [ ] 보스 HP 4 → 3: HP바 60% 표시
- [ ] 비보스 HP 4 → 3: HP바 75% 표시 (비보스는 MAX_HP=4)
- [ ] 비보스 HP 3 → 2: HP바 50% 표시
```

### 5. 페이즈 전환 애니메이션 (10분)
```
밤 페이즈 → 낮 페이즈 진행
- [ ] 밤 페이즈: 배경 어두움 (color-bg-deep)
- [ ] 낮 페이즈: 배경 밝음 (color-bg)
- [ ] 전환 부드러움 (500ms 이상)
- [ ] 배경이 갑자기 바뀌지 않음
```

### 6. 타이머 상태 (10분)
```
타이머 카운트다운 중
- [ ] 타이머 > 30초: 금색 (정상 상태)
- [ ] 타이머 ≤ 30초: 주황색 (경고 상태) + 깜빡임 애니메이션 시작
- [ ] 타이머 ≤ 10초: 크림슨색 (긴급 상태) + 깜빡임 애니메이션 계속
```

### 7. 기능 검증 (15분)
```
게임 진행 중
- [ ] "강제진행" 버튼 클릭 → 페이즈 변경
- [ ] "시간 연장" 버튼 클릭 → 타이머 추가 시간
- [ ] 모든 제어 버튼 작동
- [ ] 게임 진행 (밤/낮 사이클) 정상
- [ ] 게임 종료 → 승리 화면 표시
```

### 8. 반응형 디자인 (15분)
```
Chrome DevTools Device Toolbar로 테스트
- [ ] 375px (모바일): 1열 그리드, 헤더 2rem, 타이머 2.4rem
- [ ] 768px (태블릿): 3열 그리드, 헤더 2.2rem, 타이머 3rem
- [ ] 1920px (TV/데스크톱): 4열 그리드, 헤더 2.8rem, 타이머 4rem
- [ ] 모든 크기에서 레이아웃 깨지지 않음
```

### 9. 접근성 (10분)
```
Chrome DevTools → Lighthouse
- [ ] 성능 점수 60 이상
- [ ] 접근성 점수 확인
- [ ] 텍스트 대비: 4.5:1 이상 (DevTools Accessibility 탭)
- [ ] 포커스 링 명확함
- [ ] 버튼/카드 크기 44×44px 이상

Mac/Windows 접근성 설정
- [ ] 모션 감소 활성화 후: 애니메이션 즉시 완료 또는 비활성화
```
